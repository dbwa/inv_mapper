Comment récupérer l’UID pour la synchronisation

Qu’est-ce que l’UID ?

L’UID (User IDentifier) est votre identifiant utilisateur au sein de l’application FlashInvader. Il s’agit d’un code unique, généré aléatoirement lors de l’installation de l’application, qui permet de vous identifier lors de chaque connexion entre votre application et les serveurs du jeu. Cet UID est utilisé pour accéder à vos informations personnelles (liste de flashs, liste d’amis, etc.).

Étapes pour récupérer l’UID sur Android (Je ne sais pas le faire sur IOS)

1. Installer ADB sur votre ordinateur

ADB (Android Debug Bridge) est un outil fourni avec le SDK Android.
Téléchargez et installez le SDK ou Android Studio depuis cette page.

Après l’installation, ouvrez une fenêtre de commande (cmd ou PowerShell) :

  • Sur Windows, appuyez sur Win + R, tapez cmd ou powershell, puis validez.
  • Tapez adb et appuyez sur Entrée.
    Si l’aide d’ADB s’affiche, c’est que tout fonctionne.

2. Activer les options développeur sur le téléphone

Pour activer les options développeur, suivez ce guide officiel.

3. Connecter le téléphone à l’ordinateur

Branchez votre téléphone en USB.
Dans les options développeur, activez le débogage USB.

4. Vérifier la connexion

Dans la fenêtre de commande, tapez : 

adb devices

Vous devriez voir une ligne ressemblant à ceci : 

List of devices attached
22610JEGR16066  device

Si votre appareil n’apparaît pas, vérifiez que le mode de connexion USB est bien réglé sur "aucun transfert de fichier" ou "transfert de fichiers", et que le débogage USB est activé.

5. Récupérer l’UID

Dans la même fenêtre de commande, lancez : 

adb logcat | findstr "api.space-invaders.*uid=[^&]*$"

Sur votre téléphone, ouvrez l’application FlashInvader et naviguez dans les onglets (classements, galerie, etc.).
Vous devriez voir apparaître des lignes comme : 

05-04 17:23:29.857 21959 21959 D Help    : load url: https://api.space-invaders.com/flashinvaders_v3_pas_trop_predictif/app_web/account/highscore?uid=2a621490-8cd3-46cc-b12f-7e4009b

Votre UID est la partie après uid=, par exemple :
2a621490-8cd3-46cc-b12f-7e4009b

Copiez cet UID et enregistrez-le dans l’interface invader-mapper.
